La autorización para sumar la medición de vibración a una visita de abono está pendiente de confirmación con el equipo. El supuesto se aplica únicamente a ese escenario ficticio.

Este mapa parte del inventario operativo del 1.2 y de los [modelos vigentes](../servicios/models.py). Los campos de la tabla describen qué información buscar. Los encabezados, identificadores, fórmulas y excepciones quedan pendientes de cotejo con copias de las planillas. La importación de datos reales requiere aprobación expresa.

**Referencias cruzadas.** Si las hojas traen documentos, conservá el tipo, número, serie y fuente tal como figuran. En **Cierre administrativo**, una llamada SAP se identifica por **cliente + referencia**. OC, presupuesto, pedido y comprobantes sirven para vincular registros con la evidencia correspondiente. Una referencia compartida entre varios trabajos justifica revisar el vínculo antes de agruparlos. La fecha y referencia de factura provienen de SAP. La Agenda General de Excel sigue siendo la fuente oficial de programación.

## Criterios para revisar las copias

1. Pedir una copia anonimizada o ficticia de cada planilla, con las hojas, encabezados, fórmulas, listas y filtros. Usar los mismos códigos ficticios para un cliente, planta o equipo cuando se repitan entre archivos.
2. Conservar el valor original al cotejar y registrar archivo, hoja, fila e ID de origen cuando exista. Tratar códigos y comprobantes como texto para conservar ceros iniciales. Comparar variantes de nombre como candidatos y revisar los conflictos entre fuentes.
3. Clasificar cada coincidencia como mismo registro, vínculo entre registros o caso por resolver. Por ejemplo, dos filas con la misma visita y distinto técnico pueden ser dos asignaciones. Dos filas del mismo abonado y mes con facturas distintas requieren validar cómo se registran esos comprobantes.
4. Completar la equivalencia columna por columna con las copias y devolver el listado de faltantes, conflictos y decisiones. Esperar la aprobación antes de importar datos reales.

## Vista previa de Contratos y Equipos

En Chrome, entrá con `oficina.demo` y elegí **Clientes → Vista previa de importación**. La vista compara dos CSV ficticios incluidos en el repositorio con las fichas del entorno. Usa **Industrias Horizonte** y las plantas **Norte** y **Depósito**, que vienen de la carga ficticia del Codespace.

El informe muestra **Fila original**, **Dato encontrado** y **Resultado y motivo**. La primera columna permite desplegar las celdas de origen. La segunda muestra la ficha existente o la fila de la muestra usada para el cotejo. Cuando dos filas de Contratos difieren, sus valores quedan enfrentados en esas dos columnas. Las propuestas, coincidencias, duplicados, traslados, desgloses y revisiones son resultados de lectura.

### Hojas y columnas mínimas para la copia anonimizada

| Hoja o equivalente | Columnas y datos mínimos |
| --- | --- |
| **Contratos** | Código de cliente, referencia de contrato, inicio y fin de vigencia, alcance, frecuencia, importe y moneda. Cobertura general y códigos de planta y equipo cuando la cobertura esté en la misma hoja. Si existen, mantener OC, HES, portal y observaciones para comparar todos los campos. |
| **Cobertura o Anexos**, si se guarda por separado | Código de cliente, referencia, inicio de vigencia, código de planta y código de equipo cubierto. Incluir identificador de anexo o fila si ya existe. |
| **Equipos** | Código de cliente, código de equipo, nombre, número de serie, código de planta y ubicación. Si existen, conservar código anterior, planta anterior y fecha del cambio. |
| **Plantas** o nomenclador | Código de cliente, código de planta y nombre. Conservar alias y dirección cuando sirvan para identificar una sede. Si el código de cliente difiere entre libros, sumar la equivalencia de código interno y SAP. |
| **Hojas que alimentan el importe o ajuste**, si hay fórmulas | Celdas referenciadas y sus encabezados, por ejemplo importe base, índice o porcentaje, período y moneda. Mantener la fórmula en la celda original y el resultado visible, además de sus referencias a otras hojas. |

Mandá una copia `xlsx` por libro con sus encabezados y nombres de hoja originales. Preservá formatos de fecha y ceros iniciales. Usá los mismos identificadores ficticios para la misma entidad en todos los libros. Una muestra corta alcanza si trae un traslado, un cambio de código con la misma serie, una planta faltante, un desglose de cobertura y un conflicto de importe o alcance.

### Decisiones pendientes

- Confirmar si el equipo con otro código y la misma serie es el mismo y resolver la sede del equipo sin planta identificada. Los contratos que dependan de este último quedan pendientes.
- Resolver qué fuente prevalece cuando difieren importe o alcance. Confirmar qué filas de cobertura se desglosan y cuáles corresponden a un anexo.
- Cotejar con las copias los identificadores, encabezados y fórmulas. La muestra actual usa valores ya expresados en los campos del sistema y la vista previa es de solo lectura. La importación real requiere aprobación.
