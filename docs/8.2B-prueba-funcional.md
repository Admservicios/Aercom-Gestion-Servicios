# 8.2B · Prueba funcional con el equipo

## Preparación del anfitrión

Usá el Codespace de prueba en la rama `desarrollo/piloto-demo`. Ejecutá este bloque en su terminal antes de empezar.

```bash
git pull --ff-only origin desarrollo/piloto-demo &&
bash .devcontainer/iniciar.sh --reiniciar &&
DJANGO_SECRET_KEY="$(cat .aercom-demo/django.key)" python manage.py cargar_escenario_82b
```

La carga imprime la fecha, los números del pedido, del ticket correctivo, de la visita inicial y de la solicitud de facturación. Usa el día de Buenos Aires. Consultá las claves locales de las cuentas ficticias en `.aercom-demo/cuentas.json` desde tu terminal. En **Puertos**, abrí en Chrome el puerto privado **8000** y entrá como `responsable.demo`. Compartí pantalla para recorrerlo con el equipo. Para simular el celular, abrí la vista de dispositivos de Chrome con un ancho de 390 px.

Si ejecutás la carga dos veces para el mismo día, quedan los mismos registros y se conserva lo guardado por el equipo. Con `--fecha AAAA-MM-DD` podés preparar una segunda jornada con tickets y pedido propios, compartiendo cliente, equipos, contrato y control mensual. Para repetir la prueba desde el estado inicial, incluidas la programación y la factura del mismo mes, usá un Codespace de prueba nuevo. Los datos ficticios de esta práctica se identifican con el código de cliente **FICT-82B**.

## Verificado y por validar

En PostgreSQL y Chromium se comprobó la carga repetida, el recorrido con las cuatro cuentas, el guardado móvil a 390 × 844, el acceso directo denegado a una visita ajena y la independencia entre la ejecución de Campo, el abono mensual y el correctivo. El formulario de visita iniciado desde un pedido ahora permite volver a ese pedido.

En la revisión con el equipo queda por validar si los nombres y accesos son claros, y cuánto tarda el recorrido en sus dispositivos y condiciones habituales. También queda abierta una regla de autorización. Por ejemplo, durante una limpieza de abono, ¿Coordinación puede sumar la medición de vibración para preparar una cotización o primero necesita autorización del abonado? En este escenario ficticio se permite sumar la medición. La reparación queda pendiente de cotización.
