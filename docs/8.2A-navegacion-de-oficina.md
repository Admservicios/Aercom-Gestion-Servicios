# 8.2A · Navegación e inicio de Oficina

Implementado en `desarrollo/piloto-demo` a partir de `2c4f514`.

- El inicio muestra las visitas agendadas para hoy, las acciones que siguen pendientes y las solicitudes de facturación visibles para el usuario en estado Solicitada o Documentación pendiente. Cada bloque muestra el total, hasta tres registros y el acceso al listado correspondiente.
- El menú lateral marca el módulo activo en las vistas de Oficina. En pantallas angostas se abre desde **Menú**. Abonados y Terceros reutilizan los filtros de Clientes. Las alertas de campo se consultan desde **Mis avisos** y la **Pantalla de oficina** conserva la vista de ancho completo para el televisor.
- Las reglas de acceso de cada vista siguen aplicándose a los enlaces directos. Oficina ve el resumen según sus permisos de facturación y Campo conserva **Mis tareas** como inicio.
- Se verificaron los recorridos con datos ficticios en PostgreSQL y Chromium. No hay migraciones nuevas.

## Segunda pasada visual

- El menú permite plegar los grupos. Al navegar se abre el grupo del módulo actual y se destaca su acceso. En celular sigue disponible desde **Menú**.
- Los módulos de Oficina comparten un encabezado con la acción principal donde corresponde. Recordatorios agrupa el mensaje y la creación cuando está vacío. El listado muestra asunto, fecha o próxima visita, responsable y estado. Clientes y Facturación usan el mismo formato adaptable, e Inicio mantiene sus tres bloques principales.
- Se comprobó el flujo con datos ficticios en Chromium a 1366 × 768 y 390 × 844, con Recordatorios vacío y después de crear registros por fecha y por próxima visita.

Ejecutá este comando en la terminal del Codespace desde la rama de trabajo.

```bash
git pull --ff-only origin desarrollo/piloto-demo && bash .devcontainer/iniciar.sh --reiniciar
```
