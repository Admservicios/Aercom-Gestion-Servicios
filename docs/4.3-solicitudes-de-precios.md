# 4.3 · Solicitudes de precios e historial

**Solicitudes de precios** está en el Menú de Oficina para Administración de Servicios, Comercial y el responsable del área. La bandeja busca por código o descripción y permite filtrar pedidos pendientes o con respuesta. Se puede iniciar un pedido desde la bandeja, una cotización o un repuesto de una solicitud técnica. El sistema registra la fecha, el destinatario y quién asentó el pedido. La comunicación con Compras se sigue haciendo por el canal habitual.

Una solicitud admite más de una respuesta. Cada una guarda fecha, precio, moneda, proveedor o fuente, vigencia opcional, detalle y quién la registró. Consultar respuestas anteriores permite decidir si un precio está vigente antes de solicitarlo de nuevo. **Pedir actualización de precio** crea un pedido relacionado con el anterior y conserva sus respuestas. Si se elimina un renglón de repuesto durante una corrección técnica, el registro de precios conserva el código y la descripción consultados.
